# SINGLE_CYCLE_MIPS_GENERATOR

Software Name: Single-Cycle MIPS Core Generator

Purpose: Compiles a source code written in MIPS assembly language, and generates the RTL design of the 32-bit Single-Cycle MIPS core automatically

Feature: Supports the entire MIPS integer instruction set (81 instructions)

Supported Operating System: Linux (Ubuntu 24.04 Noble)

Command: ./MIPS_G -f source_file_name.asm

Example Command: ./MIPS_G -f ./NARAYANA_NUM.asm

Processor Architecture Reference: https://www.amazon.com/Computer-Organization-Design-MIPS-Architecture/dp/0124077269
